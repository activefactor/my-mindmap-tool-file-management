追加の確認質問はせず、既存の設計・方針に沿って以下を判断した。

- **フロントエンドルーティングライブラリ**: `react-router-dom` v7 を採用（基本設計書 §12
  未決定事項 No.3 を解消）。サーバー側の認証フローが `/dashboard` `/login?error=...` への
  パスベースのリダイレクトを前提に実装済みで、URLと画面の対応が必須要件になっているため。
  ADR `mindmap-tool/docs/adr/20260801_フロントエンドルーティングライブラリ選定.md` に記録。

- **自分自身の無効化も禁止**: 設計書は「自分自身のロール変更の禁止」しか書いていなかったが、
  自己無効化も同種の自己締め出し事故であり、本人には復旧手段が無いため禁止に含めた。
  設計書 §3.2 に追記（v2.5）。
- **`DashboardPage` は受け皿のみ**: 本実装は Step 7。ログイン後のリダイレクト先として
  存在が必要なため、最小限のプレースホルダとして作成した（Step 7 の作業を先取りしない）。

  `APP_URL` が 8080 を指しているため、ログイン後のリダイレクト先が PHP 側になり
  React の画面に戻ってこない。Google Cloud Console に
  `http://localhost:5173/api/auth/google/callback` を追加し、`.env` を 5173 に切り替えると
  解消する（開発ステップ書 Step 4 の残項目に記載）。
- 上記の対応後、ブラウザで管理コンソールの操作確認を行う。
